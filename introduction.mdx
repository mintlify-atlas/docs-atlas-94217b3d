Delta Chat is a secure instant messenger for Android that uses email infrastructure to deliver messages. Instead of routing your conversations through a proprietary server controlled by a single company, Delta Chat sends and receives messages using the email system — the same open, distributed network that has connected people for decades.

You keep your existing email address, choose your own provider, and chat with anyone who has an email address, whether or not they use Delta Chat.

## Key features

### Privacy and identity

Delta Chat does not require a phone number, a real name, or any personal information to get started. When you use a [Chatmail](https://chatmail.at) server for instant onboarding, you can create an account without providing anything beyond a chosen display name.

Contacts can only message you if you have exchanged contact details with them — unknown senders cannot reach you without your consent, which eliminates unsolicited messages by default.

### Security

Delta Chat uses [Autocrypt](https://autocrypt.org) for end-to-end encryption. Keys are exchanged automatically in the background; you do not need to manage PGP keys manually. For high-security scenarios, you can verify contacts using QR codes to establish guaranteed encryption.

The encryption implementation has been independently audited. Messages are encrypted before leaving your device and can only be decrypted by the intended recipient.

### Flexibility

You can run multiple independent chat profiles from the same app, each connected to a different email account. This makes it easy to keep personal and professional communication separate without installing multiple apps.

Delta Chat also works on low-bandwidth and unreliable connections. Because it builds on email, it inherits the robustness of IMAP and SMTP — messages are delivered even when recipients are temporarily offline.

### Extensibility with Webxdc

Chats in Delta Chat can host [Webxdc](https://webxdc.org) apps — small, sandboxed web applications that run directly inside a conversation. These include collaborative tools like shared shopping lists, calendars, polls, and games. Webxdc apps work without internet access during use; the app itself is shared as a message attachment.

## Architecture overview

Delta Chat Android is built on two main components:

- **[Chatmail Core](https://github.com/chatmail/core)** — a cross-platform Rust library that handles all messaging logic: IMAP/SMTP communication, encryption, contact management, and the local message database. The Android app communicates with this library over a JSON-RPC interface.
- **Android UI** — a native Android application that provides the chat interface, onboarding flows, notifications, and media handling.

This separation means the core protocol logic is shared across Delta Chat clients on iOS, desktop, and Android, while the user interface is tailored to each platform.
