The `chat.delta.rpc` package provides a typed Java client for the Delta Chat JSON-RPC API. All files in this package are auto-generated from the core's schema — do not edit them by hand.

## Why JSON-RPC

The JSON-RPC layer was introduced to replace the legacy JNI bindings for new features. Its advantages:

- **Type safety** — all request parameters and response fields are declared as Java POJOs.
- **Generated from schema** — when the core adds or changes an API, regenerating the bindings brings Java up to date automatically.
- **Asynchronous by design** — calls serialise to JSON, pass through the FFI boundary, and responses are received on a background thread.
- **Richer types** — the generated types carry full Javadoc from the Rust source, including field-level documentation.

## Regenerating bindings

After updating the core submodule, regenerate the Java bindings with:

```bash
./scripts/update-rpc-bindings.sh
```

This script reads the JSON schema exported by `deltachat-core-rust` and writes new Java source files to `src/main/java/chat/delta/rpc/`. The output includes `Rpc.java` and everything under `types/`.

<Warning>
Do not edit files inside `src/main/java/chat/delta/rpc/` manually. The header comment `/* Autogenerated file, do not edit manually */` is present in every generated file. Your changes will be overwritten the next time `update-rpc-bindings.sh` runs.
</Warning>

## Using the Rpc class

<Steps>
  <Step title="Create the transport">
    Obtain the `DcJsonrpcInstance` from `DcAccounts` and wrap it in an `FFITransport`:

    ```java
    DcJsonrpcInstance jsonrpc = dcAccounts.getJsonrpcInstance();
    FFITransport transport    = new FFITransport(jsonrpc);
    ```
  </Step>
  <Step title="Construct Rpc">
    ```java
    Rpc rpc = new Rpc(transport);
    ```
  </Step>
  <Step title="Call methods">
    Every method on `Rpc` throws `RpcException` on failure:

    ```java
    try {
        int accountId = rpc.addAccount();
        rpc.setConfig(accountId, "addr", "user@example.com");
        rpc.setConfig(accountId, "mail_pw", "secret");
        rpc.addOrUpdateTransport(accountId, loginParam);

        List<Account> accounts = rpc.getAllAccounts();
        FullChat chat = rpc.getFullChatById(accountId, chatId);
        Message msg   = rpc.getMessage(accountId, msgId);
    } catch (RpcException e) {
        Log.e(TAG, "RPC error: " + e.getMessage());
    }
    ```
  </Step>
  <Step title="Process events">
    Poll for events in a background thread. Events are typed via the `EventType` hierarchy:

    ```java
    while (running) {
        Event event = rpc.getNextEvent(); // blocks until an event arrives
        EventType type = event.eventType;
        if (type instanceof EventType.IncomingMsg) {
            EventType.IncomingMsg incoming = (EventType.IncomingMsg) type;
            showNotification(incoming.chatId, incoming.msgId);
        } else if (type instanceof EventType.MsgsChanged) {
            EventType.MsgsChanged changed = (EventType.MsgsChanged) type;
            refreshChatList(changed.chatId);
        }
    }
    ```
  </Step>
</Steps>

## Error handling

`RpcException` is thrown whenever the core returns a JSON-RPC error response. It carries the error message string from the core. Always catch it at the call site and surface it appropriately — most failures are non-fatal and should be shown as a non-blocking UI notification rather than a crash.

```java
try {
    rpc.deleteTransport(accountId, addr);
} catch (RpcException e) {
    Snackbar.make(view, e.getMessage(), Snackbar.LENGTH_LONG).show();
}
```

## Type reference

### Account

`Account` is a sealed class with two subtypes, discriminated by a `kind` JSON property.

```java
// kind = "Configured"
Account.Configured {
    Integer id;
    String  addr;          // email address, may be null
    String  displayName;   // may be null
    String  color;         // hex color string
    String  profileImage;  // path to avatar, may be null
    String  privateTag;    // user-set label e.g. "Work", may be null
}

// kind = "Unconfigured"
Account.Unconfigured {
    Integer id;
}
```

Obtain an `Account` with `rpc.getAccountInfo(accountId)` or a list with `rpc.getAllAccounts()`. Use `instanceof` checks to determine the subtype:

```java
Account account = rpc.getAccountInfo(id);
if (account instanceof Account.Configured) {
    Account.Configured cfg = (Account.Configured) account;
    showAvatar(cfg.profileImage, cfg.color);
}
```

### FullChat

`FullChat` contains the complete information about a single chat. Retrieve it with `rpc.getFullChatById(accountId, chatId)`.

```java
FullChat {
    Integer             id;
    String              name;
    ChatType            chatType;       // SINGLE, GROUP, MAILINGLIST, etc.
    Boolean             isEncrypted;    // true = all messages encrypted, key-contacts only
    Boolean             archived;
    Boolean             pinned;
    Boolean             isMuted;
    Boolean             canSend;
    Boolean             isSelfTalk;
    Boolean             isDeviceChat;
    Boolean             isContactRequest;
    Boolean             isUnpromoted;   // group created but no message sent yet
    Boolean             selfInGroup;    // whether self is a current member (groups only)
    Boolean             wasSeenRecently;
    String              color;
    String              profileImage;   // may be null
    String              mailingListAddress; // may be null
    Integer             freshMessageCounter;
    Integer             ephemeralTimer;
    List<Integer>       contactIds;
    List<Integer>       pastContactIds;
}
```

<Note>
`isEncrypted` being `false` means the chat uses address-contacts and unencrypted messages. The UI should mark such chats with a mail-letter icon and disable group management options (add/remove members, QR invite, avatar).
</Note>

### Contact

`Contact` is the JSON-RPC counterpart of `DcContact`. Retrieve it with `rpc.getContact(accountId, contactId)`.

```java
Contact {
    Integer id;
    String  address;        // email address
    String  name;           // name set by contact
    String  authName;       // name authenticated by core
    String  displayName;    // best name to show in UI
    String  nameAndAddr;    // "Name <addr>" or just "addr"
    String  color;
    String  status;
    String  profileImage;   // may be null
    Integer lastSeen;       // unix timestamp
    Boolean wasSeenRecently;
    Boolean isBlocked;
    Boolean isVerified;
    Boolean isKeyContact;   // identified by PGP fingerprint, not email address
    Boolean e2eeAvail;      // encryption key is known
    Boolean isBot;
    Integer verifierId;     // ID of the contact that introduced this contact; may be null
}
```

**Displaying verification state:**

- `verifierId != null` → show "Introduced by [name]" with a green checkmark.
- `verifierId == null && isVerified` → show "Introduced" with a green checkmark.
- `verifierId == null && !isVerified` → show nothing.

### TransportListEntry

Returned by `rpc.listTransportsEx(accountId)`. Represents a single configured email transport.

```java
TransportListEntry {
    EnteredLoginParam param;        // login parameters entered by the user
    Boolean           isUnpublished; // true = not advertised to contacts
}
```

`isUnpublished` transports receive messages but are not sent to contacts as a known address. Use `rpc.setTransportUnpublished(accountId, addr, unpublished)` to toggle this.

---

### WebxdcMessageInfo

Retrieved from the core for a message with `viewType = WEBXDC`. The equivalent of calling `DcMsg.getWebxdcInfo()` in the JNI layer.

```java
WebxdcMessageInfo {
    String  name;               // app name; defaults to filename
    String  icon;               // icon filename inside the .xdc zip
    String  document;           // document name if app represents a document; may be null
    String  summary;            // short status string set by the app; may be null
    String  sourceCodeUrl;      // source URL; may be null
    Boolean internetAccess;     // true if full internet access is granted
    Integer sendUpdateInterval; // minimum ms between sendUpdate() calls
    Integer sendUpdateMaxSize;  // maximum serialised update size in bytes
    String  selfAddr;           // address for window.webxdc.selfAddr
}
```
